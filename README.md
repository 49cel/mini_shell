# Operating Systems Project

This is a mini Unix shell built from scratch using C, demonstrating core OS concepts like process creation, execution, and inter-process communication

To run it:

1. Clone the repo using `git clone https://github.com/49cel/mini_shell`

2. Compile the build using `make` (Ensure you have all the dependencies sorted out)

3. You can now run it using `msh` or `./msh` in your terminal (Kitty is preferred over other native terminals)
